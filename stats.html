Privacy

Telemetry is optional in the launcher. It is used for public aggregate stats only and can be turned off in Options at any time. Public stats use app version, WoW version, renderer, macOS version, and the configured realmlist value. Daily charts count each anonymous install once per day; selected-period totals count each install once per reported value across that period.
